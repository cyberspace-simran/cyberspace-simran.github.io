## 🛠️ How it's built

- **One file.** `index.html` holds all the HTML, CSS and JavaScript. No build step, no framework, no dependencies.
- **Fonts:** Bricolage Grotesque, Instrument Serif and JetBrains Mono, from Google Fonts.
- **Interactions:** a custom cursor with labels, magnetic buttons, scroll-driven sideways slides, drag-and-drop, and confetti.
- **Accessible by default:** keyboard navigation, focus states, screen-reader labels, and a calm version for anyone with *reduce motion* switched on. The custom cursor switches itself off on touch screens.

## ✏️ Updating the content

All of the text lives in one block near the bottom of `index.html`. Search for:

```js
window.PORTFOLIO = {
```

| Key | Controls |
|---|---|
| `projects` | Case studies. `feature: true` puts a project in the sideways slides; `false` puts it in the library |
| `roles` | The "Which Simran do you need?" tabs |
| `releases` | The career timeline |
| `stats`, `specs` | The spec sheet |
| `moments` | Cards on the moments wall |
| `toolbox`, `certs` | Skills and certifications (`pending: true` shows an "in progress" badge) |
| `faq`, `issues` | Recruiter FAQ and the known-issues list |

House rule: **real numbers only, and prototypes are labelled as prototypes.**

## 🚀 Run it locally

```bash
git clone https://github.com/cyberspace-simran/cyberspace-simran.github.io.git
cd cyberspace-simran.github.io
python3 -m http.server 8000   # then open http://localhost:8000
```

Or just double-click `index.html`.

The live site is served by **GitHub Pages** from the `main` branch. Push a change and it's live within a minute or two.
